# 26 - If I Were Designing A Deal With A Vietnamese Studio

## Goal
Create a LinkedIn infographic that shows how to design a partnership ladder for a Vietnamese Studio instead of forcing a one-shot deal.

## Viewer Benefit
The viewer should get a simple partnership progression model. Publishers can use it to reduce risk while giving Studios a visible growth path. Studios can use it to understand what evidence they must earn before asking for better terms.

## Core Message
The first deal should not pretend both sides already trust each other. It should create a ladder where better capability unlocks better responsibility.

Fairness is not only a better split. Fairness is a visible path to become a stronger partner.

## Data Points To Include
- 5 ladder levels: Production Partner, Prototype Partner, Product Partner, Operating Partner, Strategic Partner.
- 8 contract questions: IP, Data, Source Code, Milestones, UA Feedback, Postmortem, Reuse Rights, Next Deal Condition.
- 1 rule: every deal should teach the Studio how to deserve a better one.
- 2026-2029 implication: Publishers that build partner ladders will access better Vietnamese teams earlier.
