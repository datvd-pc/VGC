# 36 - Junior Game Designer

## Goal
Create a LinkedIn infographic for junior Vietnamese Game Designers who need stronger fundamentals in level design, player psychology, and measurable learning.

## Viewer Benefit
The viewer should get a compact checklist for evaluating whether a level builds player trust. It should help young Designers move beyond “harder is better” and think in terms of clarity, fairness, feedback, retry motivation, and return reason.

## Core Message
A level is not a content block. It is a trust engine.

Good level design teaches the player what matters, tests that understanding, gives fair feedback, and creates a reason to try again.

## Data Points To Include
- 5 trust bars: Clarity, Fairness, Feedback, Retry Motivation, Return Reason.
- 2 learning sentences: “What does the player learn?” and “What does the player try next?”
- 3 bad patterns: unclear rule, unfair failure, no recovery path.
- 1 warning: difficulty is not the same as quality.
- 2026-2029 implication: AI can generate content, so human Designers need stronger judgment.
