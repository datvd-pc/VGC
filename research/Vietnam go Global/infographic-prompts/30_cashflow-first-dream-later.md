# 30 - Cashflow First, Dream Later

## Goal
Create a LinkedIn infographic that helps Vietnamese game talent and small Studios understand why cashflow discipline must come before big global ambition.

## Viewer Benefit
The viewer should get a practical survival lens: choose work that pays now, teaches something, creates reusable assets, or opens better relationships. It should help them avoid romantic strategy without runway.

## Core Message
Dreaming big is useful only when the team survives long enough to compound. In Vietnam’s early global-game stage, cashflow is not small thinking. It is the base layer for learning and leverage.

## Data Points To Include
- 4 cashflow questions: Does it pay now? Does it teach? Does it create assets? Does it open a better relationship?
- 3 dangerous traps: prestige project with no margin, hit-chasing without runway, service work with no learning.
- 3 healthy uses of cashflow: buy Data, improve pipeline, protect focus.
- 1 rule: do not spend like a hit Studio before you have hit-level evidence.
- 2026-2029 implication: pragmatic Studios will survive long enough to catch opportunity.
