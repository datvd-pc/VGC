# Infographic Prompt - Article 49

Article: `49_achievement-metrics-that-matter.md`

## Goal
Separate vanity activity from Achievement Metrics that prove Vietnam operating progress.

## Viewer Benefit
The viewer should get a metric filter: if a number does not change priority, support, budget, training, partner selection, or the next decision, it is noise.

## Core Message
Activity is not progress. A useful metric changes priority, support, budget, training, partner selection, or the next decision.

## Data Points To Include
- 5 metric levels: Activity, Signal, Capability, Revenue, Repeat.
- Activity examples: meetings, event leads, submissions, prototypes reviewed.
- Signal examples: qualified leads, playable quality, genre fit, data readiness.
- Capability examples: iteration speed, communication reliability, metric literacy, feedback adoption.
- Revenue examples: launch revenue, monetization signal, CPI/LTV quality, cashflow contribution.
- Repeat examples: second-deal rate, referral rate, repeat partner revenue, churn reason.
- 1 weekly sentence: "Because this number changed, our next decision is..."
