## 41 - Vietnam Needs Publisher Operating Systems, Not More One-Off Deals

Status: ready to rewrite from raw draft.

Target reader:

- foreign Publishers entering Vietnam;
- strategic Investors;
- ecosystem builders;
- senior Vietnamese Studio founders.

Goal:

Show that Vietnam is no longer only a production market. The missing layer is a repeatable Publisher operating system.

Old question:

How do we sign more games?

Better question:

How do we build a Publisher operating system that compounds Deal Flow, trust, learning, and portfolio returns in Vietnam?

Evidence to use:

- Vietnam 2025 output signal: about 4.9B downloads, roughly 95% outside Vietnam, about 210 active Studios, more than 27,000 new games.
- VECOM e-commerce analogy: platform businesses win through seller acquisition, onboarding, trust, payment, dispute handling, and repeat behavior.
- Publisher operating comparatives: Voodoo, TapNation, SayGames, Unity Supersonic.

Past / Present / Future:

- Past: Publisher as buyer, Studio as supplier, traffic cheaper, mechanics travelled further.
- Present: traffic cost, attribution noise, AI output inflation, and creative fatigue make one-off sourcing weaker.
- Future: the best Publisher wins by building a local operating layer that improves every partner loop.

Main keyword:

**Operating Model.**

Core mechanism:

Six operating layers:

1. sourcing;
2. qualification;
3. deal design;
4. support;
5. governance;
6. retention.

Scenario logic:

- If Publisher behaves like a volume buyer, Studio behaves like a vendor.
- If Publisher behaves like a platform, Studio behaves like a partner.
- If Vietnam lacks this operating layer, it exports output more easily than it captures value.

Multi-role view:

- Publisher: build repeatability, not only campaign volume.
- Studio: evaluate Publisher by decision quality, feedback, data, and repeat value.
- Investor / operator: treat publishing as an operating-system business, not a simple intermediary.

Scorecard:

- Deal Flow quality;
- Studio capability improvement;
- repeat partner rate;
- time from first contact to qualified decision;
- learning retained after launch.

7-14 day action:

Map the current publishing process into the six layers. For each layer, answer: what becomes faster, clearer, or more valuable because this layer exists?

Infographic input:

- 6-layer Operating Model board;
- output vs value capture gap;
- 3 compounding metrics: Deal Flow quality, capability improvement, Repeat Business.

Sharp close:

Publishing is no longer only about buying games. In Vietnam, the bigger opportunity is building the system that makes better games and better partners repeatable.

## 42 - Deal Flow Architecture

Status: ready to rewrite from raw draft.

Target reader:

- Publisher BD leads;
- publishing PMs;
- Vietnam market scouts;
- Studio founders who want to be found and qualified.

Goal:

Explain that Deal Flow is not networking luck. It is designed infrastructure.

Old question:

Where can we find more Vietnamese Studios?

Better question:

How do we design sourcing, qualification, prioritization, and conversion so the best Studios do not disappear inside a noisy pipeline?

Evidence to use:

- Vietnam has strong game output but uneven Studio maturity.
- Startup ecosystem analogy: pipeline quality and early support decide later investability.
- E-commerce analogy: seller acquisition only works when onboarding and trust systems exist.

Past / Present / Future:

- Past: lead lists, referrals, event contacts, cold messages.
- Present: many Studios, many prototypes, uneven readiness, inconsistent communication.
- Future: Publishers with better pipeline design will see the same market earlier and cleaner than competitors.

Main keyword:

**Deal Flow Architecture.**

Core mechanism:

Four-stage funnel:

1. source;
2. qualify;
3. prioritize;
4. convert.

Scenario logic:

- If every Studio receives the same attention, the best leads wait too long and weak leads consume the team.
- If qualification is explicit, both sides know what to improve before the next conversation.
- If response SLA exists, trust starts before the first deal.

Multi-role view:

- Publisher: build intake criteria and SLA.
- Studio: prepare materials that reduce evaluation friction.
- Investor / operator: track pipeline quality, not only number of leads.

Scorecard:

- genre fit;
- team maturity;
- playable quality;
- data readiness;
- communication reliability;
- iteration speed;
- monetization understanding;
- trust risk.

7-14 day action:

Create a one-page Studio intake scorecard and define three SLAs: first response time, review time, and pilot decision time.

Infographic input:

- source -> qualify -> prioritize -> convert funnel;
- Studio intake scorecard;
- SLA board.

Sharp close:

Deal flow is not luck. It is the first infrastructure layer of a serious publishing strategy.
