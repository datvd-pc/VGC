# Phase 4 Mindset Guide

## Core Shift

Phase 4 is not another content phase about Studios.

It is about Publisher Operating Systems in Vietnam.

The reader should feel:

> This person does not only understand game production. He understands how to build the local operating layer that foreign Publishers need if they want Vietnam to become a repeatable advantage.

## Positioning

The voice should position Dat as:

- local market interpreter;
- Publisher operating advisor;
- Studio selection / nurture strategist;
- ecosystem builder;
- practical bridge between foreign capital and Vietnamese execution.

Do not position him only as:

- writer;
- analyst;
- generic consultant;
- motivational voice for Studios.

## Main Thesis

Vietnam already has production signal.

The next opportunity is building the system around that production:

- Deal Flow;
- trust;
- Studio qualification;
- capability transfer;
- portfolio governance;
- Repeat Business.

## Writing Mindset

Every article should answer four questions:

1. What changed in the market?
2. What does this reveal about Vietnam?
3. What system should a Publisher build?
4. What should be done in the next 7-14 days?

## Infographic Mindset

Every article must be drawable.

If it cannot become a simple visual, the idea is still too abstract.

Use:

- layers;
- funnels;
- ladders;
- scorecards;
- dashboards;
- flywheels;
- before / after comparisons;
- decision trees.

Do not use:

- vague ecosystem clouds;
- generic strategy pyramids;
- slogans without metrics;
- stock business icons only.

## Required Visual Input Per Article

Each article must include at least one:

- number;
- timeline;
- metric;
- level system;
- checklist;
- operating flow;
- decision rule.

## Tone

English-first.

Direct.

Strategic.

Practical.

No hype.

No generic Vietnam cheerleading.

No negative stereotyping of Vietnamese Studios.

Use this framing:

> Vietnam does not lack production talent. It lacks enough repeatable operating systems around that talent.

## Repeated Pattern

Use this rhythm:

```md
The question is not:
"How do we get more X?"

The better question is:
"How do we build the system that makes X repeatable?"
```

## Good Phase 4 Sentences

- "Deal flow is not luck. It is infrastructure."
- "Studio selection is capital allocation."
- "Events are not branding. They are signal capture."
- "Capability transfer is the real retention mechanism."
- "Revenue is a portfolio outcome, not only a hit outcome."
- "Repeat business is the moat."

## Bad Phase 4 Sentences

- "Vietnam has many talented Studios."
- "Publishers should support Studios more."
- "The ecosystem needs collaboration."
- "Events are important for networking."

These are too generic unless they are followed by mechanism, metric, and action.

## 7-14 Day Action Standard

Every article must end with a task like:

- build a Studio intake scorecard;
- define response SLA;
- create event follow-up pipeline;
- map 4 portfolio buckets;
- create a 6-week nurture calendar;
- build Repeat Business dashboard.

If the action cannot be done within 7-14 days, it is too vague.

## Final Test

Before publishing any Phase 4 article, ask:

- Would a foreign Publisher learn how to work with Vietnam better?
- Would a Vietnamese Studio understand how to become more attractive?
- Would an Investor understand what operating layer is missing?
- Can this article become a useful infographic?
- Does the article make Dat more hireable as advisor/operator?

If any answer is no, rewrite.
