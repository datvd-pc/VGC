# VGC

Repo nội dung cho series LinkedIn về mobile game, Vietnam game market, và cách làm việc với nhân sự game Việt Nam.

## Structure

- `Mobile_Game_Stay_Hungry_Dont_Be_Foolish/`: series bài đã/đang viết.
- `planning/`: định hướng, target audience, roadmap, style guide.
- `research/`: research brief, số liệu, so sánh, market references.
- `drafts/`: nháp thô và bài đang phát triển.
- `assets/`: hình ảnh và media dùng cho bài viết.
