# Infographic Prompt - Article 07

## Goal
Show that mobile game success is now an ecosystem problem, not only a production problem.

## Core Message
Making the game is only one layer. The winning teams connect Product, Data, UA, IP, Live Ops, Monetization, and Publisher strategy.

## Data Points To Include
- 2025: Vietnam mobile game Studios reached about 4.9B downloads.
- Roughly 95% of Vietnamese mobile game downloads came from outside Vietnam.
- Market shift: 2022-2026 moved from production advantage to operating advantage.
- 2026-2029 prediction: the gap widens between Builders and Operators.

## Text On Image
Mobile Game Success Is No Longer Just About Making Games
