# 08 - Publishers Are Not The Same

## Goal
Create a LinkedIn infographic that compares major mobile game Publisher archetypes and shows why Vietnamese Studios should not treat all Publishers as the same partner.

## Viewer Benefit
The viewer should quickly understand which Publisher model fits which Studio situation. Foreign Publishers see strategic self-awareness. Vietnamese Studios learn how to choose partners based on operating needs, not brand name alone.

## Core Message
Different Publishers optimize for different games, teams, timelines, and risk profiles.

A Studio that sends the same pitch to Voodoo, Lion Studios, Supersonic, Rollic, and other Publishers is already showing weak market understanding.

## Data Points To Include
- 4 Publisher archetypes: Scale Machine, Creative Testing Network, Portfolio Operator, IP/Brand Operator.
- Example strategic signals: Voodoo leans into scale, apps, AI, and high-volume testing; Supersonic focuses on publishing tools and Data-driven prototyping; Rollic grew from Hyper-Casual into broader Casual/Hybrid; Lion Studios historically emphasized creative testing and UA capability.
- 5 comparison criteria: Traffic, Data, Creative Testing, Live Ops, IP/Legal.
- 2022-2026 context: Hyper-Casual pressure pushed many Publishers toward Hybrid Casual, Casual, Apps, tools, and deeper operations.
- 2026-2029 prediction: Publisher fit matters more because generic prototype supply is abundant.

Include takeaway “Same Pitch To Every Publisher = Weak Market Read.” Minimal icons, no real logos, clean mobile-readable layout.

## Avoid
Avoid using official Publisher logos. Avoid declaring one Publisher as universally best. Avoid crowded company history. Avoid vague “top publisher” ranking.

## Quality Check
The viewer should understand that Publisher strategy must be matched to Studio capability and game stage.
