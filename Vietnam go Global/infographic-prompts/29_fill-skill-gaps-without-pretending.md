# 29 - Fill Skill Gaps Without Pretending

## Goal
Create a LinkedIn infographic that helps Vietnamese game talent close skill gaps practically instead of hiding them, exaggerating capability, or learning randomly.

## Viewer Benefit
The viewer should get a simple skill-gap operating model: diagnose the missing capability, find examples, use AI and tools, practice with real work, and prove improvement through output.

## Core Message
The fastest way to grow is not pretending you already know. It is making the gap visible, then building a repeatable learning loop around it.

In global work, pretending creates hidden risk. Clear gaps can be managed. Hidden gaps become expensive.

## Data Points To Include
- 5-step learning loop: Diagnose, Collect Examples, Use Tools/AI, Practice On Real Work, Show Evidence.
- 6 common gaps: English Briefing, Data Reading, Level Design Logic, PM Follow-Up, Monetization Thinking, Technical Pipeline.
- 3 proof artifacts: before/after work, decision note, postmortem.
- 1 rule: do not sell maturity you cannot operate.
- 2026-2029 implication: AI makes learning faster, but weak judgment still shows in output.
