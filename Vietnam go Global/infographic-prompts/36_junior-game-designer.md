# Infographic Prompt - Article 36

## Goal
Teach Junior Game Designers to think in player trust, not only difficulty.

## Core Message
A level should create clarity, fairness, near-miss, retry motivation, and a reason to return.

## Data Points To Include
- 5 trust bars: Clarity, Fairness, Near-Miss, Retry Motivation, Return Reason.
- 2 learning sentences: this level is testing whether the player can..., the player failed because...
- 1 design rule: difficulty is not the same as quality.

## Text On Image
A Level Is A Trust Engine

An arcade level design review screen.
