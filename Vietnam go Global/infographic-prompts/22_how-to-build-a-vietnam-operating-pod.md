# 22 - How To Build A Vietnam Operating Pod

## Goal
Create a LinkedIn infographic that shows foreign Publishers how to work with Vietnamese talent through a small operating pod instead of treating Vietnam as a loose outsourcing market.

## Viewer Benefit
The viewer should leave with a practical team blueprint. A Publisher can use it to reduce communication risk. A Vietnamese Studio can use it to understand which missing roles block global collaboration.

## Core Message
Vietnam does not need a huge team to work globally. It needs a small pod with clear ownership, Data loops, communication hygiene, and decision discipline.

The right pod is small enough to move fast but complete enough to learn.

## Data Points To Include
- 6 core roles: Local PM, Dev Lead, Game Designer, Analytics Layer, Creative Bridge, Publisher PM.
- 3 operating habits: Write Before Build, Review Before Scale, Record Before Move On.
- 6-8 week test window for collaboration maturity.
- 2022-2026 context: remote work and global publishing made coordination cheaper, but misalignment more expensive.
- 2026-2029 implication: the winning Vietnam model is not cheap labor. It is repeatable operating capacity.

## Visual Structure
Use an arcade team-selection screen. Put 6 role cards in a 2x3 grid, each with one short responsibility line. Place 3 habit badges underneath. Use limited icons: clipboard, code bracket, chart, megaphone. Keep strong color contrast.

## Image Prompt
Create a premium editorial infographic in a retro arcade team-selection style. Overall style: Modern gaming industry analytics mixed with nostalgic 16-bit pixel art aesthetics. Bright warm ivory background, subtle pixel grid, bold black text, red header, cyan role-card outlines, neon green readiness badges, amber highlights. Show six clean role cards: Local PM, Dev Lead, Game Designer, Analytics Layer, Creative Bridge, Publisher PM. Add three habit badges: Write Before Build, Review Before Scale, Record Before Move On. Add formula “Operating Pod = Roles + Rituals + Data Loop”. Fewer icons, more white space, mobile-readable text.

Add a clean bottom footer strip: left side text "Author: Dat Dao | linkedin.com/in/datvd90"; bottom-right reserved white square placeholder labeled "QR Code" with enough quiet-zone margin for a real QR to be added later; do not generate a fake scannable QR code.

## Avoid
Avoid showing a corporate org chart. Avoid crowded character art. Avoid implying Vietnam is only low-cost labor. Do not use tiny role descriptions.

## Quality Check
The viewer should understand immediately what roles are needed, why the pod exists, and how it helps Publishers collaborate with Vietnamese teams.
