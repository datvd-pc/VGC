# Achievement Metrics That Matter

Stay Hungry. Don't Be Foolish.

The question is not "Are we active in Vietnam?" The better question is "Which metrics prove that our Vietnam Operating System is getting better?"

Activity is seductive: more meetings, more events, more leads, more submissions, more prototypes. But activity is not progress. A Publisher can look busy while pipeline quality is poor. A Studio can look productive while learning very little.

**Achievement Metrics.**

Five-level metric ladder:

1. **Activity** - meetings, event leads, submissions, prototypes reviewed. Useful but shallow.
2. **Signal** - qualified leads, playable quality, genre fit, Data readiness, Founder learning speed. Noise becomes information.
3. **Capability** - iteration speed, communication reliability, metric literacy, feedback adoption, process improvement. Shows whether the Studio is becoming more valuable.
4. **Revenue** - launch revenue, CPI/LTV quality, monetization signal, capital efficiency. Shows economic output.
5. **Repeat** - second-deal rate, referral rate, repeat partner revenue, churn reason, time to next collaboration. Shows whether trust is compounding.

> A metric is useful only if it changes a decision.

If a number does not change priority, support, budget, review cadence, hiring, training, or partner selection, it is reporting noise. Keep no more than three metrics per level.

Public signal (LinkedIn posts, event photos, announcements) helps attract attention. Operating signal proves attention is becoming value. They must be separated.

For Studios: do not only count levels made or builds shipped. Ask whether level quality improved, whether each build tested a clearer hypothesis, whether repeated mistakes decreased.

> Do not measure noise. Measure compounding.
