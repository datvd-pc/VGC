# Events Are Market Infrastructure

Stay Hungry. Don't Be Foolish.

The question is not "Should we sponsor or attend more game events in Vietnam?" The better question is "How do we turn events into qualified signal, follow-up discipline, pilot opportunities, and repeat relationships?"

Events look like branding, networking, panels, photos. But the real value is market memory. Who did you meet? What signal did you capture? Which Studios are qualified? Which conversations should become pilots? If the event cannot answer those questions, it is a temporary room, not infrastructure.

**Signal Capture.**

Five-stage event funnel: Attendance -> Qualified lead -> Structured follow-up -> Pilot -> Repeat contact or repeat deal. The event itself is only stage one. Real value begins after the room closes.

In e-commerce, seller events matter only if they feed onboarding. In startup ecosystems, demo days matter only if they create investable follow-up. Publishing events should be judged the same way - not "how many people came?" but "what did the ecosystem learn, and what business can happen next?"

Some strong Vietnamese Studios are quiet - they may not pitch aggressively or have perfect English materials. A good event system reveals them. A bad system rewards only the loudest teams.

> Do not call an event successful until the follow-up is complete.

Every qualified Studio should leave with one of four statuses: Pilot discussion, Nurture path, Not now, or Referral to a better-fit partner.

Event follow-up pipeline - five columns: Attended, Qualified, Follow-Up Sent, Pilot Candidate, Repeat Contact. Assign one owner. Set one follow-up deadline. Define one pilot rule. After the event, run a 30-minute review: what did we learn about Vietnam that we did not know before?
